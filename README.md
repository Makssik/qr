# QR Event Manager

Система управління учасниками подій з генерацією та скануванням QR-кодів.

---

## 🚀 Запуск

```bash
npm install
npm run dev
```

Після запуску dev-сервер буде доступний за адресами, які відобразяться в терміналі:

```
➜  Local:   https://localhost:3000/
➜  Network: https://192.168.x.x:3000/
```

> **Важливо:** Сервер працює через **HTTPS** (самопідписаний сертифікат) — це необхідно для доступу до камери на мобільних пристроях.

## 📱 Підключення з телефону

### Варіант 1: Спільна Wi-Fi мережа

**Умови:**
- Комп'ютер та телефон підключені до **одного Wi-Fi роутера**
- Роутер не блокує трафік між пристроями (більшість домашніх роутерів не блокують)

**Кроки:**
1. Запустіть `npm run dev` на комп'ютері
2. В терміналі знайдіть рядок `Network: https://192.168.x.x:3000/` — це IP вашого комп'ютера
3. На телефоні відкрийте браузер (Safari / Chrome)
4. Введіть цю адресу: `https://192.168.x.x:3000`
5. Браузер покаже попередження про сертифікат:
   - **iOS Safari**: натисніть «Додатково» → «Перейти на сайт»
   - **Android Chrome**: натисніть «Додатково» → «Перейти на сайт (небезпечно)»
6. Готово! Сайт відкриється, камера та синхронізація працюватимуть

### Варіант 2: Точка доступу з телефону (Hotspot)

**Умови:**
- Телефон роздає мобільний інтернет як точку доступу
- Комп'ютер підключений до цієї точки доступу

**Кроки:**
1. Увімкніть точку доступу на телефоні
2. Підключіть комп'ютер до точки доступу телефону
3. Запустіть `npm run dev` на комп'ютері
4. В терміналі з'явиться IP вигляду `https://172.20.10.x:3000/` — це типова підмережа iOS-хотспоту
5. На телефоні відкрийте браузер та введіть цю адресу
6. Прийміть попередження про сертифікат
7. Готово!

> 💡 **Підказка:** IP `172.20.10.x` — стандартна підмережа для iOS-хотспоту. Для Android це може бути `192.168.43.x`.

### Варіант 3: Без мережі (тільки один пристрій)

Якщо ви працюєте лише з комп'ютера або лише з телефону:
- Відкрийте `https://localhost:3000` у браузері — все працює локально

## 🔄 Синхронізація даних

Дані **автоматично синхронізуються** між всіма пристроями в мережі кожні 4 секунди:
- Імпортуйте Excel на комп'ютері → учасники з'являться на телефоні
- Відскануйте QR на телефоні → статус оновиться на комп'ютері

**Як це працює:** Dev-сервер має вбудований `/api/sync` endpoint, який зберігає дані у файл `server-db.json`. Всі підключені пристрої автоматично обмінюються даними через цей endpoint.

## 📋 Основні функції

| Сторінка | Опис |
|----------|------|
| 📊 **Дашборд** | Загальна статистика: кількість учасників, відсканованих, прогрес |
| 📥 **Імпорт** | Завантаження Excel файлів з учасниками (підтримка кількох листів) |
| 👥 **Учасники** | Список учасників з пошуком, фільтрами, швидким додаванням |
| 🏫 **Колективи** | Групи колективів з деталями та статистикою присутності |
| 🏷️ **QR Коди** | Генерація та завантаження QR-кодів (по одному або ZIP-архівом) |
| 📷 **Сканер** | Сканування QR-кодів камерою або з фото, вхідний контроль |
| 📋 **Журнал** | Історія всіх сканувань з часом та статусами |

## ⚠️ Частті проблеми

### Камера не працює на телефоні
- Переконайтесь, що адреса починається з `https://` (не `http://`)
- Дозвольте доступ до камери у спливаючому вікні браузера
- Якщо дозвіл був відхилений раніше — зайдіть у налаштування браузера → дозволи сайтів → камера → дозволити

### Камера не працює на ноутбуці
- Перевірте що інші програми (Zoom, Teams) не використовують камеру
- Дозвольте доступ до камери у спливаючому вікні браузера
- Альтернатива: використайте кнопку «📁 Завантажити з фото»

### Телефон не бачить сайт
- Переконайтесь, що обидва пристрої в **одній мережі**
- Перевірте правильність IP-адреси (вона показується в терміналі після `npm run dev`)
- Спробуйте вимкнути VPN на обох пристроях
- Перевірте що файрвол комп'ютера не блокує порт 3000

### QR-код не сканується
- Спробуйте завантажити QR як фото через кнопку «📁 Завантажити з фото»
- Переконайтесь що QR-код чіткий та не розмитий
- Збільшіть QR-код натиснувши на нього на сторінці QR Кодів
